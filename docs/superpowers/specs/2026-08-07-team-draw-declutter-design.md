# 조뽑기(Connect) 화면 정리 — 설계

작성일: 2026-08-07
상태: 승인됨 (구현은 Connect 죽은코드 정리 작업 커밋 후)

## 배경

조뽑기 화면(`src/features/connect/Connect.tsx`, 커넥셔너 그룹)이 너무 난잡하다는 피드백.
관찰된 원인:

1. **참여자 선택이 화면 절반을 차지** — 파트 3개 섹션 + 멤버 칩이 항상 펼쳐진 채라,
   사람이 몇 명뿐이어도 세로로 길게 늘어진다.
2. **불균형** — 조건 컨트롤 3개가 왼쪽에 좁게 몰리고, 오른쪽엔 크고 텅 빈 검은 뽑기
   무대가 덩그러니 놓여 시선이 분산된다.
3. **흐름이 안 읽힘** — 전부 세로로 쌓여 "① 참여자 → ② 조건 → ③ 섞기 → 결과"의
   자연스러운 순서가 사라졌다.

## 방향 (사용자 승인: "한 화면 정리")

한 화면을 세 구역으로 또렷하게. 위저드/좌우 2단이 아니라 단일 스크롤을 정돈한다.

### ① 참여자 (기본 접힘)
- 기본은 **전체 선택** 상태로 **접어 둔다**. 요약 바만 보인다:
  `👥 N명 참여 · 파트별 3종` + `참여자 고르기` 펼침 버튼.
- 펼치면 지금의 파트별 선택(전체/해제·검색·파트 선택·멤버 칩)이 나온다. 단, 더 컴팩트하게
  (칩 크기·여백 축소). 다 고르면 다시 접어 요약만 남긴다.
- 목적: 대부분 "전체로 조 짜기"라 굳이 매번 큰 명단을 펼쳐 둘 이유가 없다. 접으면 화면이 확 깔끔.

### ② 조건 + '조 섞기' (핵심 행동)
- 섞기 조건 / 편성 기준 / 조 개수(또는 조당 인원)를 **가로로 정돈한 한 줄 카드**로.
- 그 아래(또는 오른쪽 끝) **큰 '조 섞기 시작' 버튼**을 이 화면의 주행동으로 강조.
- 인원 대비 조 개수 경고(예: "참여자 3명이라 4개 조로 못 나눠요")는 빨간 박스 대신
  버튼 근처 작은 보조 문구로 차분하게.

### ③ 결과 (뽑을 때만 무대)
- 지금은 큰 검은 뽑기 무대가 늘 떠 있어 빈 공간이 크다. **뽑는 중/직후에만** 무대를 보인다.
- 평소(뽑기 전)에는 조용한 빈 상태(작은 안내 한 줄) 또는 무대 자체를 접는다.
- 뽑고 나면 그 자리에 조 결과 카드 그리드 + 공유/저장.
- 최근 저장 결과는 맨 아래 유지(현행).

## 유지 / 범위

- 조 편성 로직(`buildBalancedTeams`, 섞기 조건, 편성 기준)·저장·공유는 그대로. **레이아웃/노출만 정리.**
- three.js 뽑기 무대(`DrawCanvas`)는 유지하되 "뽑을 때만" 노출로 바꾼다.
- 커피뽑기 잔재 제거는 **별도 진행 중인 정리 작업**이 담당 — 이 작업은 그 뒤에 얹는다.

## 손대는 파일 (예상)

- `src/features/connect/Connect.tsx` — 참여자 패널 접이식화, 조건/버튼 정돈, 무대 조건부 노출.
- `src/styles.css` — `.connect-*` 레이아웃 정리(요약 바, 컴팩트 칩, 무대 접힘).

## 구현 순서 주의 (동시 편집 충돌)

`Connect.tsx`·`styles.css`를 지금 **백그라운드 정리 작업**이 커밋 안 된 채 수정 중이다.
**그 작업이 커밋된 뒤** 최신 상태 위에서 이 개선을 구현한다(git status 로 깨끗함 확인 후 착수).

## 검증

- 참여자 접힘 상태에서 화면이 짧고 깔끔한가. 펼침/접힘 동작.
- 조건 한 줄 + 큰 섞기 버튼이 주행동으로 읽히는가.
- 뽑기 전 검은 무대가 화면을 안 먹는가. 뽑는 중/후 무대·결과 정상.
- `npm run build`·`npm test` 통과.
